# wannnphoneee

A tiny browser game where you tap a phone to earn coins, level up, and buy upgrades.

## ว��ธีเล่น

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. หรือรัน local server เช่น:

```bash
python -m http.server 8000
```

แล้วเปิด http://localhost:8000

## ฟีเจอร์

- Tap to gain coins
- Level up and increase goals
- Upgrade tap power
- Buy passive auto income
- Responsive layout for desktop and mobile
